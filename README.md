# Ro-Theme

Ro masaüstünün KDE Plasma teması: Ro Açık ve Ro Koyu global temaları, Plasma stilleri, renk şemaları,
pencere dekorasyonu, panel düzeni, simgeler, açılış (Plymouth) ve GRUB teması.

Fedora 44 için `ro-theme` RPM paketi olarak dağıtılır.

> Bu depo 2.0.0 sürümüyle yeni altyapıya taşınmaktadır; kurulum ve geliştirme belgeleri bu süreçte eklenecek.
