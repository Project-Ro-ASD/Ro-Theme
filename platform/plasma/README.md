# Plasma

Ro Plasma tarafı üç ayrı katmandan oluşur:

- Color scheme: Uygulama, pencere, klasör ve metin paletlerini değiştirir.
- Plasma style: Panel, dock, popup ve widget yüzeylerinin rengini/görünümünü belirler.
- Global theme: Color scheme, Plasma style, splash, layout ve wallpaper seçimini beraber uygular.

Dark/light wallpaper değişimi yalnızca global theme tarafında tutulur. `.colors`
dosyaları bilerek wallpaper içermez; sadece renk paletinden sorumludur.
