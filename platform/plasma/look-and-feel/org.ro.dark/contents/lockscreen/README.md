# Ro Kilit Ekranı

Bu klasörde yalnızca Ro kilit ekranı wallpaper varlığı tutulur.

`LockScreen.qml` özellikle gönderilmez; KDE'nin kendi güvenli kilit açma arayüzü,
saat alanı ve oturum doğrulama akışı kullanılmaya devam eder. Ro görünümü
wallpaper, aktif color scheme ve Plasma style üzerinden uygulanır.
